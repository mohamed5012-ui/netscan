-----------------------------------------------------------
ملف الـ EXE والـ APK بيتبنوا على GitHub (مش موجودين جوّا الـ zip)
-----------------------------------------------------------
السبب: بناء exe محتاج سيرفر ويندوز، وبناء apk محتاج أدوات أندرويد.
GitHub بيعملهم لك مجانًا في السحابة. الخطوات:

1) فُك ضغط netscan-project.zip

2) اعمل مستودع Private على GitHub باسم netscan
   من: https://github.com/new   (من غير README)

3) من داخل مجلد المشروع، نفّذ:
     git init
     git add .
     git commit -m "netscan"
     git branch -M main
     git remote add origin https://github.com/<حسابك>/netscan.git
     git push -u origin main

4) روح تبويب Actions في المستودع — هتلاقي البناء شغّال لوحده.
   - بناء الويندوز: دقيقتين–تلاتة
   - بناء الأندرويد: 15–25 دقيقة أول مرة

5) لما يخلّص (✓)، افتح العملية ونزّل من قسم Artifacts:
   - netscan-windows-exe  →  فيه netscan.exe
   - netscan-android-apk  →  فيه ملف .apk

-----------------------------------------------------------
تشغيل سريع من غير بناء (على الكمبيوتر):
     python desktop/app.py        (واجهة)
     python cli/netscan.py        (سطر أوامر)
