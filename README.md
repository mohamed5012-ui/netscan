# 🔍 ماسح أجهزة الشبكة — netscan

برنامج بيكتشف **كل الأجهزة المتصلة بالشبكة المحلية** بشكل تلقائي، من غير ما تحدد
أي IP بإيدك. بيشتغل على:

- 🪟 **الويندوز** — ملف `netscan.exe` (واجهة رسومية، دبل كليك وخلاص)
- 🤖 **الأندرويد** — ملف `netscan.apk`
- 💻 **لينكس / ماك** — سطر أوامر
- 📱 **الموبايل (Termux)** — سطر أوامر

---

## فكرة العمل

أي جهاز على الشبكة لازم يرد على **ARP** (الطبقة الثانية) عشان يتواصل أصلًا،
حتى لو بيحجب الـ ping. البرنامج بيثير كل عنوان في الشبكة بحزمة صغيرة، وده بيجبر
النظام يكتشف الـ MAC بتاع كل جهاز ويكتبه في جدول ARP — وبكده بنلاقي تقريبًا أي
جهاز مهما كان نوعه (موبايل، كمبيوتر، راوتر، كاميرا، IoT).

على **الأندرويد الحديث** فيه قيد من جوجل بيمنع التطبيقات العادية من قراءة جدول ARP
(من غير روت)، فالتطبيق بيكتشف الأجهزة الحيّة كمان عن طريق محاولة اتصال TCP — وده
بيشتغل على أي موبايل من غير أي صلاحيات خاصة. يعني هتلاقي الأجهزة وعناوين الـ IP
بتاعتها دايمًا، وعنوان الـ MAC بيظهر على حسب ما النظام يسمح.

### المزايا

- 🔎 **اكتشاف تلقائي** لنطاق الشبكة الحقيقي والراوتر (يدعم شبكات كبيرة حتى /16).
- 🏷️ **قاعدة بيانات الشركات كاملة** (+59 ألف شركة) — بتعرف نوع كل جهاز من الـ MAC.
- 📛 **أسماء الأجهزة** من 3 مصادر: DNS العكسي + NetBIOS (ويندوز) + mDNS (أبل/أندرويد).
- ⚠️ **كشف المشاكل على الشبكة** — عمود الملاحظات بيوضّح:
  - `IP متكرر`: نفس الـ IP رد بأكتر من MAC (تعارض عناوين أو احتمال انتحال).
  - `MAC مكرر`: نفس الـ MAC ظاهر على أكتر من IP.
  - `MAC متشابه`: ماكات متطابقة ماعدا آخر خانة (غالبًا نفس الجهاز بأكتر من كارت).
  - `MAC عشوائي`: عنوان خاص/عشوائي (خاصية الخصوصية في الموبايلات الحديثة).
- 💾 **تصدير** النتائج: Excel (منسّق) أو CSV على الكمبيوتر، و CSV في مجلد التنزيلات على الموبايل.

> ملاحظة: كشف "IP متكرر / MAC مكرر" بيساعدك تلاحظ الأجهزة الغريبة أو تعارضات العناوين
> على **شبكتك أنت**. استخدمه على شبكتك أو بإذن صاحبها فقط.

## 🚀 طريقة الحصول على الـ EXE والـ APK (عن طريق GitHub)

مش محتاج تثبّت أي أدوات بناء على جهازك — GitHub هيبنيلك الاتنين في السحابة.

### 1) اعمل مستودع خاص (private) على GitHub

ادخل على <https://github.com/new> واعمل مستودع جديد باسم `netscan` واختاره **Private**.
**من غير** ما تضيف README (عشان الكود جاهز عندك).

### 2) ارفع الكود (من داخل مجلد المشروع)

```bash
cd netscan-project
git init
git add .
git commit -m "النسخة الأولى من ماسح الشبكة"
git branch -M main
git remote add origin https://github.com/<اسم-حسابك>/netscan.git
git push -u origin main
```

### 3) GitHub يبني تلقائيًا

بمجرد ما تعمل push، روح لتبويب **Actions** في المستودع. هتلاقي عمليتين بيشتغلوا:
- **بناء ملف الويندوز (EXE)**
- **بناء تطبيق الأندرويد (APK)**

> أول بناء للأندرويد بياخد حوالي **15–25 دقيقة** (بينزّل أدوات أندرويد لأول مرة).
> بناء الويندوز أسرع بكتير (دقيقتين–ثلاثة).

### 4) نزّل الملفات

بعد ما العملية تخلّص (علامة ✓ خضرا)، افتحها ونزّل من قسم **Artifacts**:
- `netscan-windows-exe` → جواها `netscan.exe`
- `netscan-android-apk` → جواها ملف الـ `.apk`

## 💻 التشغيل محليًا (من غير بناء)

### ويندوز / لينكس / ماك — الواجهة الرسومية
```bash
python desktop/app.py
```

### سطر الأوامر
```bash
python cli/netscan.py
python cli/netscan.py --prefix 24
python cli/netscan.py --no-names
```

### الموبايل عبر Termux (أندرويد)
```bash
pkg install python
python cli/netscan.py
```

- للمسح الأقوى على الكمبيوتر (يكشف الأجهزة الصامتة كمان) ممكن تثبّت `scapy` وتشغّل
  البرنامج بصلاحية مدير — لكن النسخة الحالية شغّالة كويس من غير أي تثبيت.

  شبكات IPv6-only، أو لو الراوتر مفعّل عليه عزل الأجهزة (Client Isolation).
- استخدم البرنامج على شبكتك أنت أو بإذن صاحبها فقط.
